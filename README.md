# Oval Brand Identity

The identity for [Oval](https://oval.vote), the plain-text format for voting guides, and for the
organization that publishes it. Everything here is the source: the logo, the wordmark, the colors,
the typefaces, and the tokens that the website, the renderer, the editor, and the extension draw
on. `index.html` shows all of it on one page.

## The mark

The mark is a ballot oval, filled in. It is the shape a voter darkens with a pencil, drawn as a
horizontal ellipse with width to height of 1.75 to 1: an ink fill with an outline in the marking
purple. Nothing else is in it. At small sizes, such as a favicon, the outline thins and the fill
carries it.

| File                        | Use                                                                                |
| --------------------------- | ---------------------------------------------------------------------------------- |
| `logo/mark.svg`             | The mark in color: ink fill, purple outline. The default on paper.                 |
| `logo/mark-reverse.svg`     | The mark in the dark palette, for dark paper.                                      |
| `logo/mark-mono.svg`        | One color, taken from `currentColor`, for places that allow a single color.        |
| `logo/mark-outline.svg`     | The empty oval in `currentColor`, for an "unfilled" state beside the filled mark.  |
| `logo/wordmark.svg`         | "Oval" set in Newsreader Medium at optical size 72, as outlines, in ink.           |
| `logo/wordmark-reverse.svg` | The wordmark in the dark palette.                                                  |
| `logo/lockup.svg`           | The mark beside the wordmark, the mark centered on the capitals.                   |
| `logo/lockup-reverse.svg`   | The lockup in the dark palette.                                                    |
| `logo/favicon.svg`          | A 32-pixel version with a thinner outline.                                         |
| `logo/icon.svg`             | A square app icon: the mark on paper with rounded corners, 1024 pixels.            |
| `logo/avatar.svg`, `.png`   | The square avatar for GitHub and other services that round the corners themselves. |

The wordmark and lockup files are generated by `npm run wordmark`, which downloads Newsreader
from Google's fonts repository and outlines the word with fontkit, so they contain no text and need
no font installed. CI fails when they are stale.

On dark paper use the `-reverse` files, which swap in the dark palette; a page that follows the
viewer's theme shows one or the other with a `<picture>` element and a `prefers-color-scheme`
media query, or two images toggled by the same theme rules as the tokens, as `index.html` does.

Keep clear space of half the mark's height on every side. Do not show the mark smaller than 12
pixels tall, stretch it off its ratio, rotate it, add a shadow, or put it in a color other than ink
and the marking purple, or one color from the palette. The wordmark is always Newsreader; do not set
the name in another face or add a tagline inside the lockup.

## Color

The palette is a ballot: paper, ink, and the purple that marks it.

| Token          | Light     | Dark      | Role                                                                  |
| -------------- | --------- | --------- | --------------------------------------------------------------------- |
| `paper`        | `#f2f1ec` | `#16150f` | Page background, the color of ballot stock.                           |
| `paper-raised` | `#fbfaf7` | `#211f17` | A surface lifted from the page: a card, a recommendation box.         |
| `ink`          | `#17150f` | `#ebe8df` | Text, the mark's fill, anything drawn in ink.                         |
| `ink-soft`     | `#5f5b50` | `#9d988b` | Secondary text: eligibility lines, metadata, captions.                |
| `rule`         | `#cfccc2` | `#37352c` | Hairlines, borders, table rules.                                      |
| `mark`         | `#975cc1` | `#975cc1` | The marking purple: the mark's outline, link underlines, focus rings. |
| `support`      | `#2e6b3a` | `#5fb36c` | A supported campaign or a yes recommendation.                         |
| `oppose`       | `#c4343a` | `#e2666b` | An opposed campaign or a no recommendation.                           |

Red and blue carry party meaning in American politics, so the accent is purple, which belongs to
no party, and the only red is the one that means "against" on a specific question. Support is a
green that is not a party color either.
Never use `mark` to color a party, a candidate, or a position on a question; parties are labeled
with their own abbreviations in ink.

Both themes are designed, not inverted: dark paper is warm. The purple is one value in both themes,
chosen for 4.0:1 contrast against both papers, which is as high as a single color can reach on
two grounds this far apart. That is enough for the mark, underlines, focus rings, badges, and
large text; small running text stays in ink.

## Type

| Role | Family                                                           | Weights  | Use                                                                             |
| ---- | ---------------------------------------------------------------- | -------- | ------------------------------------------------------------------------------- |
| Text | [Newsreader](https://fonts.google.com/specimen/Newsreader)       | 400, 500 | Running text, headings, and the wordmark. Variable, with optical sizes 6 to 72. |
| UI   | [Public Sans](https://fonts.google.com/specimen/Public+Sans)     | 400, 600 | Labels, controls, badges, navigation, tables of data.                           |
| Mono | [IBM Plex Mono](https://fonts.google.com/specimen/IBM+Plex+Mono) | 400, 500 | Oval source, identifiers, and code.                                             |

Newsreader is a newspaper text face, which is where voting guides have lived for a century. Public
Sans is the typeface of the United States Web Design System, so civic interfaces already read in
it. All three are open-source and served from Google Fonts; `tokens/oval.css` names the fallback
stacks.

Running text is 1.125 rem at a line height of 1.5, on a measure of 44 rem. Headings use Newsreader
at the next optical size up, and uppercase labels in Public Sans take 0.06 em of letter spacing.

## Tokens

`tokens/oval.css` declares every value above as a custom property prefixed `--oval-`, with the dark
values under `prefers-color-scheme: dark` and under `[data-theme="dark"]`, so a page can follow the
system or set a theme itself. `tokens/oval.json` is the same set as data, with a description on
each token, for tools that generate from it.

Load the CSS, then the fonts:

```html
<link rel="stylesheet" href="tokens/oval.css" />
<link rel="preconnect" href="https://fonts.googleapis.com" />
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />
<link
  rel="stylesheet"
  href="https://fonts.googleapis.com/css2?family=Newsreader:ital,opsz,wght@0,6..72,400;0,6..72,500;1,6..72,400&family=Public+Sans:wght@400;600&family=IBM+Plex+Mono:wght@400;500&display=swap"
/>
```

## Voice

Oval's writing is plain and declarative, the register of a specification: short sentences, active
voice, nouns people recognize. It does not pitch. The name is "Oval" in prose, `.oval` as a file
extension, and `oval` as the command and the keyword; never "OVAL" or "oval" at the start of a
sentence about the project.

## Using the identity

The logo and wordmark identify the Oval project. Use them to refer to Oval, to show that a tool
reads or writes the format, or to link to oval.vote. Do not use them to suggest that the project
endorses a guide, a candidate, a party, or a position, and do not modify them.

## Developing

```sh
npm ci
npm run wordmark   # regenerates logo/wordmark.svg and logo/lockup.svg from Newsreader
npm run avatar     # regenerates logo/avatar.png from logo/avatar.svg
npm run check      # formatting and that the generated files are current; CI runs this
```

Open `index.html` in a browser to see the identity on one page.

## Publishing

Every push to `main` that passes `npm run check` deploys the page to GitHub Pages. `npm run build`
assembles `dist/` from `index.html`, `logo/`, and `tokens/`, and the workflow uploads that
directory, so nothing else in the repository is served.
